# OpenLayers Tutorial

This repository contains learning materials source-code for creating interactive web maps with **OpenLayers**, developed by UTU Geospatial Labs for geospatial education and practical learning.

The tutorial introduces the main concepts and guides you through building your own webmap step by step.

 **[Open the tutorial](https://utu-geospatial-labs.github.io/openlayers-tutorial/)** to view the published learning materials.

 [Resulted OpenLayers webmap](https://utu-geospatial-labs.github.io/openlayers-webmap/)
 

You can also explore the source files and contribute to the tutorial through this repository.
